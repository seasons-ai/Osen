# Проверочные фразы скилла osen

Набор для ручной проверки описания (`description`) скилла: на какие просьбы владельца он срабатывает, а на какие нет. Текст скилла английский, просьбы владельца бывают на русском и на английском — в обоих списках есть строки на двух языках.

## Скилл должен сработать

| Фраза владельца | Почему |
|---|---|
| «Собери совет моделей по вопросу, какую базу выбрать» | Прямая просьба созвать совет |
| «Обсуди с несколькими моделями, стоит ли переходить на монорепозиторий» | Явно несколько моделей |
| «Пусть модели поспорят, REST или GraphQL» | Спор моделей между собой |
| «Мозговой штурм моделей: как назвать продукт» | Штурм именно силами моделей |
| «Созови совет из Claude и Codex и пусть договорятся по архитектуре» | Названы участники, нужно согласие |
| «Хочу, чтобы несколько ИИ обсудили мой план релиза и выдали общее решение» | Другая формулировка, та же суть |
| «Запусти совет моделей на сценарных участниках по теме кэширования» | Просьба с названными участниками, сервер разведёт расход |
| «Пусть три модели по кругу доработают это решение, пока не согласятся» | Круги и согласие, суть продукта |
| «Convene a council of models on which database to choose» | Прямая просьба созвать совет |
| «Discuss with several models whether to move to a monorepo» | Явно несколько моделей |
| «Let the models argue: REST or GraphQL» | Спор моделей между собой |
| «A brainstorm of models: how to name the product» | Штурм именно силами моделей |
| «Call a council of Claude and Codex and let them agree on the architecture» | Названы участники, нужно согласие |
| «I want several AIs to discuss my release plan and come up with a shared decision» | Другая формулировка, та же суть |
| «Start a council of models with scripted participants on caching» | Просьба с названными участниками, сервер разведёт расход |
| «Let three models refine this decision in rounds until they agree» | Круги и согласие, суть продукта |

## Скилл не должен сработать

Столбец «Опора в description» — слова описания скилла, которые отсекают фразу; `skill/skill-text.test.ts` сверяет, что каждая опора есть в описании.
