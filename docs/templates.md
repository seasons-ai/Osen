# Шаблоны обсуждений

Шаблон обсуждения — файл с готовой рамкой: как вести обсуждение и в каком виде выдать решение. В нём же можно задать роли участников и лимиты по умолчанию. Шаблон избавляет от того, чтобы каждый раз объяснять моделям, чего вы от них хотите. Свой шаблон — это один файл в папке, код менять не нужно.

Шаблон можно создать и изменить в приложении: раздел «Новое», карточка «Новый шаблон» и действия на карточках, а также кнопка «Сохранить как шаблон» в настройке сессии (см. «Редактор в приложении» ниже). Файл руками — второй способ, он описан дальше.

## Быстро: свой шаблон за три шага

Команды ниже работают с папкой `.council-data` проекта. Без `COUNCIL_HOME` они работают с настоящей папкой данных владельца.

1. Узнайте папку данных:

```bash
COUNCIL_HOME=.council-data npx council home
```

2. Создайте папку шаблонов:

```bash
mkdir -p .council-data/templates
```

Сохраните пример из следующего раздела в файл `.council-data/templates/weekly-plan.json`.

3. Проверьте, что шаблон появился в списке:

```bash
COUNCIL_HOME=.council-data npx council templates
```

Перезапускать ничего не нужно: файл подхватывается при следующем запросе списка или запуске.

## Язык встроенных шаблонов

Встроенные шаблоны и нейтральная рамка есть на двух языках: `templates/en/` и `templates/ru/` репозитория (в приложении — `Resources/templates/en/` и `Resources/templates/ru/`). Список, галерея, `council_options` и запуск берут набор действующего языка интерфейса (по умолчанию English; язык задают `COUNCIL_LANG`, `preferences.json` или «Настройки», см. README, «Язык интерфейса»). Идентификаторы, число ролей и лимиты в обоих наборах одинаковы, меняются только тексты. Если у действующего языка нет набора, загрузка отказывает с причиной, другой язык не подставляется.

Пользовательские шаблоны и своя `neutral.md` в `templates/` папки данных языка не имеют: при любом языке они показываются и применяются как написаны и перекрывают встроенный вариант на обоих языках. Рамка, скопированная в сессию при старте, не переводится: «Запустить заново» после смены языка берёт записанный текст. Название встроенного шаблона в «Истории» берётся из набора действующего языка.

## Пример файла

Путь: `.council-data/templates/weekly-plan.json`.

```json
{
  "id": "weekly-plan",
  "title": "План на неделю",
  "category": "Личное",
  "description": "Когда задач больше, чем времени, и нужно выбрать, что делать на этой неделе.",
  "exampleTopic": "Составить план на неделю: релиз, отчёт и две встречи с клиентами",
  "framing": [
    "Цель обсуждения: прийти к реалистичному плану на неделю, который помещается в доступное время.",
    "",
    "Как вести обсуждение:",
    "- Сначала назови ограничения: сколько часов есть и какие сроки жёсткие.",
    "- Для каждой задачи оцени срок и цену отказа от неё.",
    "- Факты, которых нет в теме, не додумывай: называй их допущениями.",
    "",
    "В каком виде выдать решение:",
    "1. Цель недели одной фразой.",
    "2. План по дням.",
    "3. Что отложено и почему.",
    "4. Допущения и риски."
  ],
  "roles": [
    "Скептик: ищет, что не успеется и где оценки занижены",
    "Прагматик: защищает самое важное и режет остальное",
    "Оптимист: ищет способ уложить больше за те же часы"
  ],
  "limits": { "maxRounds": 3 }
}
```

## Поля

Формат — JSON, UTF-8. Имя файла любое (лучше `<id>.json`). Лишние поля — ошибка.

| Поле | Обязательное | Что это |
|---|---|---|
| `id` | да | Идентификатор: строчные латинские буквы, цифры и дефис, начинается с буквы или цифры (`^[a-z0-9][a-z0-9-]*$`) |
| `title` | да | Название, непустая строка |
| `category` | да | Категория, непустая строка. Любая; у встроенных русских: «Архитектура и код», «Продукт и стратегия», «Выбор и решения», «Разбор проблем», «Тексты и коммуникации»; у английских — те же по смыслу, на английском |
| `description` | да | Когда брать шаблон, непустая строка |
| `exampleTopic` | да | Пример темы, непустая строка |
| `framing` | да | Рамка: строка либо массив строк. Строки массива склеиваются переводом строки, пустая строка даёт пустую строку текста. Не может быть пустой |
| `roles` | нет | Массив непустых строк: роли участников по порядку. По умолчанию ролей нет |
| `limits` | нет | Объект с необязательными `maxRounds` (круги), `turnTimeoutSec` (таймаут хода, секунды), `contextChars` (размер контекста, символы); целые не меньше 1, `turnTimeoutSec` — от 1 до 2147483 |

Читаются только файлы `*.json` прямо в папке `templates/`; подпапки и другие файлы пропускаются.

## Как шаблон применяется

- Рамка и роли копируются в сессию в момент старта. Правка или удаление шаблона потом не меняет прошлые сессии.
- Роли раздаются участникам по порядку: первому — первая, второму — вторая. Участников больше, чем ролей: лишние остаются без роли. Ролей больше: лишние не используются.
- Лимиты: флаг запуска (`--max-rounds` и другие) главнее лимита шаблона, лимит шаблона главнее значения по умолчанию из `config.json`.
- Явный `--framing <текст>` главнее рамки шаблона.

## Как писать рамку и роли

- Не пересказывайте правила протокола (формат ответа, позиции, круги): участник получает их отдельно. В рамке — как вести именно такое обсуждение.
- Назовите разделы, из которых состоит решение, пронумеруйте их.
- Давайте ролям разные интересы. Самые несогласные между собой ставьте первыми: при малом числе участников используются только первые роли.
- Факты, которых нет в теме, просите называть допущениями.
- Рамка короткая: несколько абзацев, а не страница.

## Свой вариант встроенного шаблона

Положите свой файл с тем же `id`, что у встроенного: в списке будет ваш, файл встроенного не изменяется. Чтобы вернуть встроенный, удалите свой файл. В приложении то же делают без ручной работы с файлами: «Изменить» у встроенной карточки создаёт такой файл (карточка получает метку «изменён»), «Сбросить к встроенному» его удаляет; после сброса и при «Дублировать» берётся встроенный вариант действующего языка. Список встроенных шаблонов покажет `council templates`.

## Нейтральная рамка

Тема без шаблона использует нейтральную рамку — текстовый файл `neutral.md` (встроенная лежит в `templates/<язык>/neutral.md` репозитория). Чтобы заменить её, положите свой `neutral.md` в `templates/` папки данных. Пустой файл не применяется: берётся встроенная рамка, а в ошибках загрузки появляется запись.

## Редактор в приложении

В разделе «Новое» рядом с карточкой «Своя тема» стоит карточка «Новый шаблон». У каждого исправного шаблона есть действия «Изменить» и «Дублировать»; «Удалить» — только у пользовательских шаблонов (в том числе у изменённого встроенного); у изменённого встроенного ещё «Сбросить к встроенному». Нажатие на основную область карточки по-прежнему открывает настройку сессии. Метка «пользовательский» — свой шаблон, «изменён» — пользовательский файл с идентификатором встроенного. Удаление и сброс подтверждаются внутри приложения; встроенные файлы приложение не меняет и не удаляет, прошлые сессии не затрагиваются.

Редактор «Шаблон обсуждения» содержит те же поля, что файл: название, категория (существующая или новая), описание, пример темы, рамка, роли (добавление, удаление, перестановка; список может быть пустым) и три необязательных лимита — кругов, таймаута хода в секундах, размера контекста в символах. Пустой лимит в файл не пишется. Проверка идёт той же схемой, что описана в разделе «Поля»: ошибки видны у полей, «Сохранить» недоступно, пока они есть.

- Идентификатор нового шаблона получается из названия: русские буквы транслитерируются, остальное приводится к строчной латинице, цифрам и дефисам («Ретроспектива спринта» → `retrospektiva-sprinta`); если он занят, добавляется `-2`, `-3` и так далее. Владелец его видит, но не правит; у существующего шаблона он при смене названия не меняется.
- Новый шаблон пишется в файл `<идентификатор>.json` в папке `templates/` папки данных. Правка пользовательского шаблона меняет именно его файл, даже если имя файла не совпадает с `id`. Запись идёт через временный файл в той же папке: при сбое прежний файл остаётся целым, форма сохраняет введённое и показывает причину. Существующие файлы новым шаблоном не затираются.
- «Дублировать» открывает редактор копии с названием «<название> (копия)» и новым идентификатором; файл появляется только при сохранении.
- Галерея обновляется сразу, перезапуск не нужен.

«Сохранить как шаблон» стоит в карточке «Запуск» экрана «Настройка сессии» под «Начать» и открывает тот же редактор. В нём рамка выбранного шаблона (для «Своей темы» нейтральная), роли по порядку участников, текущий лимит кругов, текущая тема в «Примере темы» и в описании; категория выбранного шаблона предложена, название пустое. Провайдеры и модели в шаблон не попадают. Сохранение создаёт новый пользовательский шаблон, не меняет исходный и `neutral.md` и не запускает сессию; сохранение и отмена возвращают к той же настройке с прежними значениями. Если тема пуста или среди ролей есть пустая строка между заполненными, редактор открывается с ошибками у этих полей.

Чего редактор не делает: не исправляет, не удаляет и не перезаписывает файлы с ошибками (они остаются прежним предупреждением с именем и причиной, чинятся руками по таблице ниже); если в папке два файла с одним `id`, правка, удаление и сброс этого шаблона отклоняются с причиной, оба файла остаются. Импорта и экспорта шаблонов, правки `neutral.md` и сохранения провайдеров и моделей в шаблон нет.

Лимит кругов в шаблоне — любое целое не меньше 1, в том числе больше 20. Форма «Настройка сессии» при запуске принимает от 1 до 20: это граница запуска, а не файла.

## Если шаблон не появился в списке

Файл с ошибкой пропускается, остальные шаблоны загружаются. Причины печатаются после списка под строкой `Ошибки загрузки:`, по строке на файл: `  <файл> (встроенный|пользовательский): <причина>`.

| Что напечатано | Что исправить |
|---|---|
| `не JSON — <сообщение>` | Файл не разбирается как JSON: проверьте запятые, кавычки и скобки |
| `<поле>: обязательное поле отсутствует` | Добавьте поле, например `framing` |
| `(корень): лишнее поле «<имя>»` | Опечатка в имени поля или поле, которого нет в формате |
| `id: значение не подходит под шаблон …` | В `id` только строчные латинские буквы, цифры и дефис |
| `<поле>: ожидается непустая строка` | Заполните поле текстом |
| `limits.maxRounds: ожидается число не меньше 1` | Целое число от 1 (так же для `turnTimeoutSec`, `contextChars`); `turnTimeoutSec` не больше 2147483 |
| `дубль идентификатора «<id>»: уже загружен из <файл>` | В одной папке два файла с одним `id`; загружен первый по алфавиту, измените `id` в другом |
| `не удалось прочитать — <сообщение>` | Файл недоступен: проверьте, что он существует и открывается |

Ошибки нет, а шаблона тоже нет:

- расширение не `.json` (например, `weekly-plan.json.txt`);
- файл лежит в подпапке `templates/`;
- файл лежит в другой папке данных: сверьте путь с `npx council home` и значением `COUNCIL_HOME`.

## Запуск по шаблону

```bash
COUNCIL_DEV=1 COUNCIL_HOME=.council-data npx council --topic "Переписать модуль отчётов с нуля или чинить по частям" --template refactoring-plan --participant scripted:packages/core/scenarios/consensus/p1.json --participant scripted:packages/core/scenarios/consensus/p2.json
```

Пример идёт на сценарных участниках и ничего не стоит. Ожидается строка `Шаблон: refactoring-plan` после строки `Тема: …`, затем `══ Итог: consensus` и код возврата 0. Неизвестный идентификатор: сессия не создаётся, ошибка называет идентификатор, код возврата 2.
